LinkedIn to Sheets Chrome Extension

A Chrome extension that extracts publicly available LinkedIn profile data and sends it directly to a Google Sheet.

🚀 What does it do?

This extension allows you to quickly collect publicly available LinkedIn profile information and store it in a structured Google Sheet.

It is designed for recruiters, researchers, and professionals who need to organize LinkedIn data efficiently.

Extracted data:

  • Name
  • Current company
  • Current position
  • Location
  • Profile URL

⚙️ How it works

  1. Open a LinkedIn profile
  2. Click the extension icon
  3. Connect your Google account
  4. Select a spreadsheet and tab
  5. Click "Paste Current Profile"

The data will be automatically inserted into your Google Sheet.

🔐 Permissions explained

This extension requires:

  • storage → to save user preferences
  • identity → to connect to your Google account
  • activeTab → to read the current LinkedIn page
  • scripting → to extract profile data

Google API scopes:

  • spreadsheets → to write data
  • drive.metadata.readonly → to list your spreadsheets

🔒 Privacy

This extension only processes data locally and writes to your selected Google Sheet.

Privacy Policy

No data is stored, tracked, or transmitted outside of the user's Google account.

🛠 Troubleshooting

Unexpected error
→ Try reconnecting your Google account

Can't select spreadsheet
→ Make sure permissions were granted

Duplicate profiles
→ The extension checks existing profile URLs before inserting
