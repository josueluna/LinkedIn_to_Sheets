LinkedIn to Sheets

Version 0.1.9

A Chrome extension that extracts publicly available LinkedIn profile data and sends it directly to a Google Sheet.

Add to Chrome Use Template View Changelog

🚀 What does it do?

Quickly collect LinkedIn profile data and store it in Google Sheets with a fast and minimal workflow.

Extracted data:

  • Name
  • Current company
  • Current position
  • Location
  • Profile URL

⚙️ How it works

  1. Open a LinkedIn profile
  2. Click the extension
  3. Connect Google
  4. Select spreadsheet & tab
  5. Click "Paste Current Profile"

✨ Features

  • 🔗 One-click LinkedIn extraction
  • 📊 Direct Google Sheets integration
  • 📁 Spreadsheet & tab selection
  • 💾 Remembers your configuration
  • 🚫 Smart duplicate detection
  • ⚡ Fast, minimal workflow

🔐 Permissions

  • storage → save preferences
  • identity → Google login
  • activeTab → read LinkedIn
  • scripting → extract data

🔒 Privacy

No data is stored or tracked. Everything stays in your Google account.
